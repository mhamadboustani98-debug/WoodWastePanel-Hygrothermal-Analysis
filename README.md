# WoodWastePanel – Hygrothermal Analysis

## Overview

This repository contains the Python scripts developed for the Master's internship entitled:

**Data analysis and hygrothermal modeling for the characterization of new bio-based materials – WoodWaste-Panel Project.**

The scripts were developed in Python using Visual Studio Code (VS Code) to process the experimental measurements collected from a full-scale outdoor test cell located in Riga, Latvia, as part of the European **WoodWastePanel** project.

---

## Repository contents

The repository includes scripts for:

- Temperature analysis of the hemp wall
- Temperature analysis of the reference wall
- Relative humidity analysis of the hemp wall
- Relative humidity analysis of the reference wall
- Water vapour pressure analysis
- Transient water vapour pressure analysis

---

## Software

The scripts were developed using:

- Python 3
- Pandas
- NumPy
- Matplotlib

---

## Purpose

The scripts were used to:

- Import and preprocess the experimental dataset.
- Remove invalid and unrealistic measurements.
- Analyse temperature evolution.
- Analyse relative humidity evolution.
- Calculate water vapour pressure from temperature and relative humidity.
- Generate the figures presented in the Master's thesis.

---

## Notes

The experimental dataset is not included in this repository because it belongs to the WoodWastePanel project consortium.

The scripts are provided to document the analysis methodology and ensure the reproducibility of the results presented in the thesis.
